Drawing Validator

Checks whether sub-drawings are consistent with their main assembly drawing (GAD).

Uploading to: Default Project

Main Drawing

The main assembly drawing (GAD) sub-drawings are checked against. Selecting a file extracts it immediately.

Sub Drawing(s)

One or more component drawings to compare against the GAD. Add as many as you like, each extracts on its own.

Job Card

Shop-floor work order PDF. Extraction only — not compared against the GAD.

DXF File(s)

Baffle cutting DXF sheet, and/or a GAD DXF (a file with "GAD" in its name). Cutting sheets are split into sub-parts now; GAD DXFs are just checked. Validation happens later, on the Run Comparison tab.

1. Compare GAD vs Sub Drawings

Cross-checks the extracted GAD against the extracted sub-drawing(s). Needs both to have been extracted on the Upload tab.

2. Job Card

Shows the job card extraction result from the Upload tab. "Compare with sub drawing" checks the job card against an uploaded heating element sub-drawing.

3. Validate DXF

Traces each split sub-part and overlays the segmental baffles on the full baffle.

4. GAD vs DXF Validation

Finds the slotted capsule holes in the GAD DXF and traces them against the baffle in the cutting-sheet DXF. Needs a GAD DXF (name contains "GAD") and another DXF, both uploaded on the Upload tab.
